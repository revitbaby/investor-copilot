## ADDED Requirements
### Requirement: China/HK Dashboard Tab
The dashboard MUST provide a dedicated tab for China and Hong Kong liquidity analysis.

#### Scenario: Navigate to China Dashboard
- **WHEN** the user selects the "🇨🇳 China/HK Liquidity" tab
- **THEN** the view switches to display CN/HK specific charts and metrics

### Requirement: China Liquidity Visualization
The dashboard MUST visualize the 3-layer liquidity framework (Macro, Meso, Micro).

#### Scenario: View China Macro Charts
- **WHEN** the user views the China Dashboard
- **THEN** charts display DR007 vs OMO Rate, M1-M2 Gap, and Social Financing

#### Scenario: View China Market Charts
- **WHEN** the user views the China Dashboard
- **THEN** charts display A-Share Turnover, Northbound Flows, and Margin Balance

### Requirement: HK Liquidity Visualization
The dashboard MUST visualize Hong Kong specific liquidity drivers.

#### Scenario: View HK Charts
- **WHEN** the user views the HK section
- **THEN** charts display AH Premium Index, Southbound Flows, and USD/CNH vs HSI
