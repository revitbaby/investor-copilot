# China A-Share Macro Regime Scoring Enhancement

> **日期**: 2026-05-09
> **状态**: Proposal（待评审）
> **前置变更**: `add-china-hk-liquidity-dashboard`、`add-regime-scoring-engine`

## 1. 背景与动机

### 1.1 现状

当前 China 模块的体制评分（`analyze_china_signals`）仅使用两个维度：
- **M1-M2 增速差**（宏观流动性陷阱信号）
- **北向资金方向**（外资情绪信号）

而北向资金实时披露已于 2024 年 8 月停止，导致外资信号维度事实上缺失，China 模块的评分结果可靠性大幅下降。

### 1.2 问题

1. **信号稀薄**：仅凭货币供应量一个维度无法区分"宽松但无效"与"宽松且有效"的市场环境
2. **估值维度缺失**：没有衡量 A 股相对吸引力的指标，无法识别"便宜"与"贵"的体制
3. **情绪维度缺失**：没有捕捉杠杆热度、市场极值情绪的哨兵机制
4. **框架不对称**：美股模块已有完整三层体制框架，China 模块仍是单层规则

### 1.3 目标

将 China 模块升级为与美股框架**对等但逻辑独立**的三层体制评分体系，新增三个核心 A 股特有估值/流动性指标，并重新定义 A 股的层间逻辑，使其适配"政策市"特征。

## 3. 新增核心指标（三个）

> 以下三个指标是 A 股宏观评估的经典"水位计"，分别从**杠杆热度**、**股债相对吸引力**、**居民资金入市意愿**三个维度衡量市场环境。

### 3.1 两融余额市值比（Margin Balance / Market Cap Ratio）

**定义**：当日融资融券余额（沪+深+京三市合计）÷ A 股总市值，单位为 %。

**业务含义**：
- 衡量当前市场**杠杆热度**
- 历史牛市高点（2015年）约 3.3%，正常区间约 1.5%–2.2%
- 超过 2.5% 视为杠杆过热；低于 1.5% 视为情绪极度低迷

**展示形式**：折线图（叠加沪深300走势）+ 历史参考水位线（2015牛市峰值、2021牛市峰值）+ 最新值卡片（含与两个历史高点的距离描述）

**更新频率**：日更

---

### 3.2 股债利差（Equity-Bond Yield Spread）

**定义**：沪深300盈利收益率（1 ÷ 市盈率TTM）- 10年期中国国债收益率，单位为 %。

**业务含义**：
- 正值越大 → A 股相对国债**越便宜**，配置价值越高
- 负值 → A 股已贵过债券，性价比低
- 历史回测显示：利差 > 3% 时往往对应买入时机；< 1% 时对应相对高估区间

**展示形式**：折线图（叠加沪深300走势）+ 历史参考水位线（2008/2015/2021牛市起点值）+ 最新值卡片 + 与历史极值的距离描述

**更新频率**：日更（国债收益率日频；PE 存在1日滞后）

---

### 3.3 存款市值比（Deposit / Market Cap Ratio，单位：倍）

**定义**：居民储蓄存款余额（或 M2 广义货币存量）÷ A 股总市值，单位为"倍"。

**业务含义**：
- 衡量**社会财富中还有多少"潜在入市资金"未被股市吸纳**
- 比值越高 → 居民资金大量停留在银行，股市吸纳比例低，潜在上涨空间大
- 比值越低（如 2015 年峰值区间）→ 居民资金已大量流入市场，边际买入力量减弱

**展示形式**：折线图（叠加沪深300走势）+ 历史参考水位线 + 最新值卡片

**更新频率**：月更（存款数据月度披露，图表以月频点显示）

## 4. A股三层体制框架

> A 股是典型的政策驱动市场，其体制特征与美股存在根本差异：美股流动性由美联储资产负债表决定，A 股则由央行货币政策窗口指导和监管政策共同驱动。三层框架必须适配这一特征。

---

### Layer 1：流动性基底（央行水位）

**对应美股层**：Net Liquidity（Fed Assets - RRP - TGA）

**A 股逻辑**：A 股流动性水位的核心信号是**银行间市场资金松紧度**（DR007 与政策利率的偏离程度），以及**货币活化程度**（M1 是否在恢复）。

**本层回答的问题**：央行当前是在向市场注水还是抽水？实体经济的货币是否在流转？

**核心信号**：

| 信号 | 含义 | 判断方向 |
|------|------|----------|
| DR007 与 OMO 利率的偏差 | 银行间市场实际资金松紧 vs 政策意图 | DR007 持续低于 OMO → 宽松 |
| M1 同比增速 | 货币活化程度（钱在流转还是躺在存款） | M1 回正/加速 → 活化 |
| M1-M2 增速差 | 流动性陷阱信号 | 差值收窄/转正 → 改善 |
| 社会融资规模增速 | 实体信用扩张信号 | 加速 → 需求回暖 |

**本层输出**：Position Ceiling（仓位上限），反映宏观流动性对权益的支撑强度

| 层一结论 | Position Ceiling |
|----------|-----------------|
| 宽松：DR007 < OMO 且 M1 回正 | 最高（如 80%） |
| 中性：信号混合 | 中等（如 60%） |
| 收紧：DR007 > OMO 且 M1 为负 | 较低（如 40%） |

---

### Layer 2：市场体制（估值 + 情绪体制）

**对应美股层**：Market Regime（SPY Trend / VIX Level / HY Credit Spread）

**A 股逻辑**：体制由三个维度共同定义——A 股相对债券的性价比（股债利差）、杠杆热度（两融比）、市场恐慌程度（期权波动率）。

**本层回答的问题**：市场当前处于何种定价状态？便宜还是贵？热还是冷？

**核心信号**：

| 信号 | 含义 | 阈值方向 |
|------|------|----------|
| 股债利差 | A 股相对债券的吸引力 | > 3% → 低估；< 1% → 高估 |
| 两融余额市值比 | 杠杆热度 | > 2.5% → 过热；< 1.5% → 冷淡 |
| A 股期权波动率指数（QVIX） | 市场恐慌程度，类比 VIX | > 30 → 恐慌；< 15 → 自满 |
| 主力资金净流入占比 | 机构资金方向 | 持续流入 → 多头体制 |

**体制分类**（A 股特有四态）：

| 体制名称 | 特征组合 | 含义 |
|----------|----------|------|
| **价值牛市** | 股债利差高 + 两融比低 + QVIX 低 | 便宜、不热、不慌，历史最佳入场体制 |
| **情绪牛市** | 股债利差中 + 两融比高 + QVIX 低 | 杠杆驱动，需关注退出节奏 |
| **恐慌底部** | 股债利差高 + QVIX 高 | 极度低估但恐慌，左侧机会 |
| **高估风险** | 股债利差低 + 两融比高 | 估值贵 + 杠杆重，系统性风险累积 |

**本层输出**：Utilization Rate（Ceiling 的使用率），反映在当前仓位上限内应使用多大比例

---

### Layer 3：即时哨兵（情绪极值 / 市场异常）

**对应美股层**：Instant Sentinels（MOVE、BTC、DXY Reversal）

**A 股逻辑**：A 股情绪极值信号最直接的来源是**涨停板市场**（A股独有的涨跌停制度），以及港资的边际行为（南向资金仍在披露）。

**本层回答的问题**：今日市场是否出现了值得立即响应的极值信号？

**哨兵列表**：

| 哨兵名称 | 触发条件 | 业务含义 |
|----------|----------|----------|
| **涨停板过热哨兵** | 当日涨停股数量 > 阈值（如 200） | 情绪过热，短期回调风险 |
| **跌停板恐慌哨兵** | 当日跌停股数量 > 阈值（如 50） | 市场恐慌，流动性危机信号 |
| **ZT/DT 比率哨兵** | 涨停数 / 跌停数极端偏离 | 市场方向性情绪的即时读数 |
| **连板热度哨兵** | 3连板以上个股数量突破阈值 | 主题炒作温度，过热预警 |
| **南向资金异常哨兵** | 单日南向净买额 > 历史均值 ±2σ | 港资大额异动，外资视角信号 |
| **成交额突变哨兵** | 全市场成交额较20日均值 > 1.5× | 量价背离，可能为转折点信号 |

**触发响应**：
- 任意哨兵触发 → 在 Dashboard 顶部显示**警告横幅**，描述触发原因
- 多个哨兵同时触发 → 哨兵层强制降低 Target Position Envelope（不论 Layer 1/2 结论）
- 哨兵状态持久化：触发后保持至少 N 个交易日（默认 3 日），避免单日噪音

## 5. 三层合成与仓位建议

### 5.1 合成逻辑

```
Target Position Envelope（A股） =
    Layer 1 Ceiling
    × Layer 2 Utilization Rate
    经 Layer 3 Sentinel Override 修正
```

Layer 3 的修正方式：
- 单哨兵触发：Envelope 降低 10%–15%
- 多哨兵同时触发：Envelope 强制降至 Layer 1 Ceiling 的 50%
- 无哨兵：不修正

### 5.2 体制历史时间轴

Dashboard 展示过去 12 个月的**体制色带时间轴**，让用户直观看到 A 股体制切换的频率和当前所处位置（类比现有美股 Regime Timeline 组件）。

## 7. 与现有框架的关系

### 7.1 与美股三层框架的关系

| 维度 | 美股框架 | A 股框架 |
|------|----------|----------|
| 流动性基底信号 | Fed Assets - RRP - TGA | DR007偏差 + M1-M2差 |
| 体制判断核心 | SPY趋势 + VIX + HY利差 | 股债利差 + 两融比 + QVIX |
| 哨兵信号 | MOVE指数 / BTC / DXY | 涨停板数量 / 连板数 / 南向异动 |
| 估值锚 | 无显式估值 | 股债利差（绝对估值判断） |

两个框架**并行运行、互不干扰**，最终在 Dashboard 上并列展示，辅助用户做全球资产配置的横向比较。

### 7.2 北向资金的替代

北向资金（实时）已停止披露，在新框架中的替代方案：
- **哨兵层**：南向资金（港股通）仍在正常披露，以港资视角替代外资信号
- **体制层**：主力资金净流入（A股内部机构资金）替代外资方向信号
- **UI说明**：在 Dashboard 的北向资金图表处保留历史数据，并明确标注"实时披露已于 2024-08 停止"
