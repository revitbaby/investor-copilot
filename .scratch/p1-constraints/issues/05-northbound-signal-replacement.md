# 05 — 北向信号替换：成交活跃度 + 季度持股方向

**What to build:** A 股流动性分析中的北向信号弃用日度净买入（2024-08 起官方停披露，之后均为估算值不采信，ADR-0009）。新信号函数（纯函数）以「成交总额（活跃度）+ 季度持股变动（方向）」组合输出调整，替换原基于 5 日累计净买入的 ±5% Utilization 调整项。取数链路切断对 2024-08 后净买入列的一切读取；新阈值写入配置并标注来源与方向性理由；UI 增加口径变更披露说明。季度持股数据源选型（及不可得时降级为"仅活跃度"并显式标注）是 spec 开放项，实施时裁定并回报。

**Blocked by:** None — can start immediately

- [ ] 体制计算链路中不再存在基于日度净买入的 ±5% 调整项
- [ ] 2024-08 后的净买入缓存列不被任何计算读取
- [ ] 新组合信号接入 A 股体制计算，阈值有配置化来源标注
- [ ] UI 有"日度净买入已停披露、估算值不采信"的披露说明
- [ ] 新信号函数测试覆盖：活跃度阈值边界、方向缺失（季度数据不可得降级）、None/缺失数据
- [ ] 季度持股数据源选型已裁定并记录在 ticket 完成说明中
