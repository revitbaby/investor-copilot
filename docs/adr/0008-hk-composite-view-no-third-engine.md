# 港股不建第三套体制引擎，采用双引擎合成视图

港股在总资产账本中是独立市场类别（有自己的基准区间与暴露统计），但不建第三套 L1/L2/L3。港股的体制约束由「A 股引擎（中国基本面/风险偏好）× 美股 L1（美元流动性）」合成（如取更保守值），这与港股的真实定价结构一致。AH 溢价、南向资金保留为港股专属展示指标（AH 溢价反哺"同一公司买 A 还是买 H"的微观决策）。

用户约束：港股仅直接持有腾讯等**极少数核心股票**，微观层只需覆盖个位数港股标的（日线数据经 AkShare/yfinance `.HK` 补齐，废弃现有"港股返回 None"的 placeholder）。

## Considered Options

- **完整第三套港股引擎**：被否——第三套阈值/哨兵状态机/历史回填使维护面扩大约 50%，而其两个真实输入（中国基本面、美元流动性）已有引擎在算，属重复建设。
- **港股并入 A 股引擎**：被否——丢掉美元流动性这半边定价逻辑；2021-2024 港股与 A 股的持续背离正源于此，合并会使约束系统性失真。
