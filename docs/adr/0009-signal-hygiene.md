# 信号卫生：北向信号重定义、魔法数字治理、Position Advisor 重构

## 1. 北向资金信号重定义

北向资金在 A 股流动性分析中定位为「重要的成交参与方（约占一成半成交）+ 蓝筹股的边际定价者」，**不是流动性总量的决定因素**。2024 年 8 月起官方已停止披露北向日度净买入，任何平台该日期之后的日度"净买入"均为估算值，**不得采信**。

替代方案：北向信号改用「**成交总额（活跃度）+ 季度持股变动（方向）**」组合。原 L2 中基于日度净买入的 ±5% Utilization 调整项废弃；现缓存 `northbound_flow.csv` 中 2024-08 之后的"净买入"数据视为污染。

## 2. 魔法数字治理（不回测、但问责）

引擎中所有阈值（VIX 35、股债利差 3%、两融比 2.5%、涨停 200 只等）按三条规则治理：

1. 每个阈值在配置文件中标注**来源与方向性理由**（历史锚点实测 vs 文献 vs 拍脑袋），拍脑袋的降权处理；
2. **年度校准审查**：每年用过去一年真实数据人眼复盘各信号的贡献（帮忙/帮倒忙），Copilot 自动生成复盘材料；
3. **不做参数优化回测**——与"绝不量化"原则一致。系统价值在"强迫纪律一致性"，不在"阈值精确"。

## 3. Position Advisor 重构而非删除

- CSV 手工上传废弃，数据源改为总资产账本（ADR-0007）；
- options/beta_spx 专属逻辑砍掉（与用户实际操作无关）；
- **保留骨架**：conviction 分级（S/A/B/C）进持仓表并扩展到 A股/港股/基金（基金 conviction 挂在替代性审查结论上）；减仓优先级排序（低信念先砍 → 高波动先砍 → 盈利仓先砍）全市场通用。
