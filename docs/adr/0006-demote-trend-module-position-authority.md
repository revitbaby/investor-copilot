# 趋势交易模块降级为"交易时参考"，确立仓位单一出处原则

现有趋势交易模块（trending-up-analysis / trading-strategy-ui spec）是一套完整的波段交易系统，与用户"中长期价值+趋势为主、短期技术指标仅作交易时参考"的哲学冲突。裁决：

- **保留**：趋势确认清单（6 项）、趋势阶段判断（5 阶段）、衰竭信号清单（9 项）——它们回答"现在是不是好的买卖时点"，正是"交易时参考"的定位。
- **删除**：金字塔仓位建议（40/30/20/10）、固定百分比止损止盈（-6.5% / +25% / +45% / 跟踪止损）——它们会诱导按短线系统操作，且其仓位数字与总资产层的权威冲突。

同时确立**仓位单一出处原则（Position Authority）**：任何仓位数字只能由总资产层给出（核心仓 = 战略基准 + 战术偏移；卫星仓 = 25% 预算 + 主线状态风控）。微观层与技术模块永远不输出仓位建议。

## Consequences

- `trending-up-analysis` spec 中「金字塔仓位建议」「止损与止盈目标计算」两个 Requirement 废弃；`trading-strategy-ui` 中的金字塔仓位计算器、体制仓位乘数横幅（BULL→1.0 等映射）废弃。
- 一键生成交易计划文本需重写：去除仓位/止损止盈栏目，只保留标的确认、入场时机、纪律红线。
