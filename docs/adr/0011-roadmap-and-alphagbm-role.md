# 实现路径：账本先行；AlphaGBM 定位为期权隐含信息参考

## 建设顺序（账本先行）

- **P0 总资产账本**：天天基金 Skill 接入 + 基金 X-Ray + 股票持仓表扩展 + 周度快照 + 目标进度仪表盘。一切裁决的计算基础，交付即有用。
- **P1 约束层改造 + 去糟粕**：战略基准区间配置、envelope 降级接入总资产层、港股合成视图（ADR-0008）、Position Advisor 重构（ADR-0009）、删除金字塔/固定止损止盈（ADR-0006）、北向信号替换（ADR-0009）。
- **P1.5 简版周报**：P0+P1 数据即可生成周报骨架，让仪式（ADR-0010）尽早运转。
- **P2 主线记分卡**：MacroMicro/InvestingPro 接入 + 证伪条件登记 + 卫星仓风控。
- **P3 微观双轨**：个股尽调卡 + 基金替代性审查。
- **P4 仪式全量**：月度/年度仪式 + Chat 查阅补充。

否决的顺序：主线先行（没有账本，"逻辑破坏"不知道砍谁砍多少）；周报先行（没有账本的周报只有市场没有"你"）。

## AlphaGBM 的角色

定位为**期权市场隐含信息参考**：IV、skew 等作为美股个股尽调卡的"市场预期"维度输入。不建期权交易/对冲模块（options 交易逻辑已随 ADR-0009 砍除）。
