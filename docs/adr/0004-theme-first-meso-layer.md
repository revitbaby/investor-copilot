# 中观层以"投资主线"为一等公民，主线状态是卫星仓唯一的硬风控

中观层不做全行业景气扫描，而是维护**少量（2-4 条）显式投资主线**（由用户定义，如 AI 算力链、AI 应用等）。每条主线一张**景气记分卡**：少量硬数据信号（MacroMicro 产业数据、InvestingPro 龙头基本面、财报节奏/指引）+ LLM 综合叙事，输出三态**主线状态**（健康 / 降温 / 逻辑破坏），不输出仓位数字。

主线状态驱动两件事：
1. **卫星仓风控**：「逻辑破坏」是卫星仓强制减仓的唯一规则化触发器（体制引擎管不到卫星仓）；证伪条件必须在主线建立时提前写下。
2. 核心仓的行业倾斜建议。

## Considered Options

- **全行业景气打分排名**：被否——本质是行业轮动量化，维护成本超出业余投资者可持续范围，且与"绝不量化"原则冲突。
- **不建规则化中观层（纯数据看板）**：被否——放弃将用户最强的认知优势（IT 从业者对 AI 的判断力）产品化；10 年周期最大的风险是"主线逻辑已死但用户没承认"，记分卡的核心价值是提前写下证伪条件。
