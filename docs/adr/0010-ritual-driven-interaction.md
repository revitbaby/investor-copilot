# 交互采用仪式驱动，Chat 仅作查阅补充

Copilot 的输出绑定固定节奏的"仪式"，看板退居查阅角色：

- **周报（核心产物）**：账本周度快照 + 各市场 envelope 与基准偏离 + 主线记分卡变化 + 卫星占比核查 + 待办动作清单（"本周无需动作"是合格周报的常态）。
- **月度审查**：基金替代性审查 + 在持个股尽调卡刷新。
- **年度仪式**：目标进度对质（ADR-0003）+ 信号校准审查（ADR-0009）。
- **事件驱动例外**：仅 L3 哨兵触发和主线「逻辑破坏」两类事件允许打破节奏主动告警。
- LLM 角色从"解释评分"扩展为"生成周报/复盘材料的分析师"，仍服从仓位单一出处原则（ADR-0006）。
- **Chat 问答**作为补充能力（问尽调卡、问数据），不是主交互。

理由：框架已用规则对抗情绪（envelope/哨兵/hold-down），但看板驱动的交互层仍在喂养情绪——信息获取节奏由焦虑水平决定。仪式驱动把"什么时候需要注意"的判断权也交给系统，服务 10 年周期的复利心态。
