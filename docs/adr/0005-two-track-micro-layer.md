# 微观层双轨制：股票尽调清单 + 基金穿透透视

微观层按持有工具分两条轨：

1. **股票轨 = 买入前尽调清单**：对候选个股输出结构化"尽调卡"——主线一致性 → 基本面质检（InvestingPro 深度指标：营收/FCF 趋势、估值分位、健康度）→ 估值对照 → 最后才是技术面时机。Copilot 产出尽调卡，买卖决策由用户做。
2. **基金轨 = X-Ray 透视 + 替代性审查**：通过天天基金 Skill 拉取基金持仓与净值，(a) 将基金穿透到市场/主线暴露并聚合进总资产账本；(b) 定期审查每只基金的存在理由（费率、超额收益、与主线/基准匹配度、更优替代——含 QDII 额度约束）。

关键理由：用户约 40% 资产为公募基金（含 QDII）。不穿透基金，总资产层对真实暴露是盲的——例如 QDII 基金里的美股 AI 持仓可能使卫星仓真实占比早已超过 25% 上限而不自知（ADR-0002 的执行依赖穿透）。

## Considered Options

- 基金只计总额不穿透：被否——使 ADR-0001/0002/0003 失去计算基础。
- 主推基金 ETF 化迁移：被否——是投资观点而非产品决策，且忽略 QDII 额度约束（想换未必换得进）。
