# 信息架构按决策层级重排（我 → 约束 → 论点 → 工具），确立三条可视化语言规则

## 页面地图

1. **首页 = 总资产**：首屏按序回答三个问题——(a) 我现在偏离基准吗（各市场实际 vs 基准区间 vs 战术目标，偏离条形图）；(b) 卫星仓穿透后真实占比超没超 25%；(c) 目标进度（真实年化 vs 17.5% 需求线）。其下为最新周报摘要 + 待办动作清单。首页不放任何市场行情图。
2. **市场约束页**：现有美股/A 股引擎页合并降级至此（gauge、评分表、哨兵行、timeline 全保留），加港股合成视图（ADR-0008）。定位：「为什么基准内该偏上/偏下」的证据页。
3. **主线页**：2-4 张景气记分卡（状态、证伪条件距离、卫星仓映射持仓）。
4. **微观页**：尽调卡工作台 + 基金审查。
5. **周报库 + 数据管理**：工件阅读器（渲染历次周报/月审/年审 markdown）+ 现有数据管理页。

理由：按市场组织的旧 IA 使"市场是主语、用户是宾语"，是看板焦虑的空间来源。新 IA 让用户大多数日子看完首页三个答案即可关掉工具——仪式驱动纪律（ADR-0010）在空间维度的执行。

## 可视化语言（全站三规则）

1. **凡有区间必画区间**：基准区间、envelope、记分卡阈值一律用色带表达，杜绝单线让用户心算越界。
2. **凡有"我"必标"我"**：市场图上叠加用户持仓暴露/成本位，统一标记符号（现有 gauge ▼ 做法推广全站）。
3. **红色只留给需要动作的东西**：哨兵触发、越界、逻辑破坏；单纯下跌不配红色。
