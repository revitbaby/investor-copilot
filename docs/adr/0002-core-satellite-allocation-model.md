# 总资产层采用核心-卫星配置模型，卫星仓上限 25%

总资产层的顶层配置逻辑采用 Core-Satellite：核心仓设**战略配置基准**（各市场/资产类的长期基准区间），宏观体制引擎（各市场 Target Position Envelope）只在基准区间内做**战术偏移**；AI 主线为**独立预算的卫星仓**，上限为总资产的 25%，有独立的仓位与风控规则，不与核心仓混算。

选 25% 的理由：10 年 5-10 倍的目标需要卫星仓贡献超额收益（10% 拉不动总账户），但 30%+ 时单一主线的回撤会伤及本金安全。

## Considered Options

- **全动态配置**（市场间分配完全由三层引擎打分驱动）：被否——本质是把总资产交给一堆未回测的阈值，与用户"绝不做量化"的原则冲突。
- **固定基准 + 定期再平衡**：被否——浪费用户 7 年经验和已建成的宏观引擎。
- 卫星仓混入核心仓统一评分：被否——AI 主线的高波动高估值特征会持续触发体制引擎的"过热"信号，导致引擎反复建议砍最高信念仓位。
