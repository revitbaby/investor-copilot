# 总资产账本采用半自动数据接入，周度快照，人民币计价

总资产账本的数据接入方式：

- **基金侧（~40%）**：天天基金 Skill 自动拉取持仓、净值、收益；X-Ray 穿透走同一条线（自动化程度最高的部分）。
- **股票侧**：手工维护持仓表（扩展现有 stock-pool 的 `holding`/`cost_basis`/`shares` 字段），用户中低频交易下维护成本可忽略。
- **现金及其他**：手工月度更新。
- **快照**：周度持久化账本估值；日度是伪精度且喂养盯盘焦虑，月度对战术偏移越界反应太慢。
- **记账货币**：人民币（三市场统一折算，汇率自动拉取；10 年 5 倍目标以人民币计）。

## Considered Options

- **全手动总额快照**：被否——到不了持仓明细级，X-Ray、替代性审查、尽调卡（ADR-0005）全部无从谈起。
- **券商 API 全自动**：被否——多券商认证/风控/接口变更的长期维护成本，远高于"月均几笔手工录入"的收益。
